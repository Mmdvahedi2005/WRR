# References

General background for the concepts used in this repository.
Only well-known textbooks and standard references are listed; no
fabricated citations are included.

1. Silberschatz, A., Galvin, P. B., & Gagne, G. *Operating Systems:
   Concepts*. Wiley. — CPU scheduling, synchronization (semaphores,
   monitors), and process management.
2. Stallings, W. *Operating Systems: Internals and Design Principles*.
   Pearson. — scheduling algorithms and real-time scheduling (EDF, RM).
3. Buttazzo, G. C. *Hard Real-Time Computing Systems*. Springer. —
   periodic tasks, EDF/RM theory, and schedulability analysis.
4. Python Software Foundation. *Python 3 Documentation* —
   `subprocess`, `threading` (`BoundedSemaphore`, `Condition`),
   `dataclasses`, `argparse`.
5. Giampaolo Rodola. *psutil documentation* —
   `Process.suspend()`, `Process.resume()`, `Process.cpu_times()`.
